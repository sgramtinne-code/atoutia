# Atoutia

Atoutia est un projet de jeu de Belote moderne, social, competitif et offline-first.

## Etat actuel

Phase 0 : preparation de l'environnement et fondations du projet.

## Principes

- moteur de Belote independant de l'interface ;
- regles deterministes et testables ;
- offline-first ;
- multijoueur server-authoritative ;
- TypeScript strict ;
- securite et equite prioritaires ;
- pas de pay-to-win ;
- qualite industrielle sans over-engineering.

## Environnement principal

Developpement local :

- Windows 11 ;
- WSL2 ;
- Ubuntu 26.04 LTS ;
- VS Code Remote WSL ;
- Node.js 24 LTS ;
- pnpm.

Le serveur OVH sera utilise plus tard pour les services online et le backend deploye.
